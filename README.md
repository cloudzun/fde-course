# AI 时代的 FDE：认知、流程、团队与中国落地

> **副题：从非标交付到平台飞轮——"卖人力"到"卖能力"的完整方法论**

一套系统讲解 **FDE（Forward Deployed Engineer，前沿部署工程师）** 的方法论与落地手册：它是什么、为什么有效、如何交付（四阶段 SOP）、如何组建团队、中国技术服务商如何对标转型，以及 AI/Agent 时代如何谈成与做成 FDE 项目。

---

## 如何阅读

- **决策层/甲方**：重点读认知篇、标杆篇、中国实践篇导读与小结，以及每篇收尾的「甲乙方对照」专栏，把握战略与 ROI。
- **中层管理者**：深读流程篇、团队篇，掌握交付方法论与组织建设。
- **一线工程师**：细读流程篇四阶段 SOP 与各类模板，并关注 AI 篇（第15–16章）的落地打法。
- **按行业检索**：金融/制造/政务读者可先读 14.5.2「三行业关切对照表」与附录 I「合规速查表」定位重点章节。

## 网站访问统计（GA4）

FDE-101 与 FDE-102 共用衡量 ID `G-DSM77VN7ZQ`。`javascripts/analytics.js` 仅在正式域名 `cloudzun.com` / `www.cloudzun.com` 的两个课程路径下采集，本地预览不计入。首屏与 Material 无刷新章节切换上报 `page_view`，同页锚点和重复挂载不重复计数。不要另外粘贴 Google tag 或配置 Material 的 `extra.analytics`，以免重复采集。

**GA4 后台必做设置**：管理 → 数据流 → 对应网站数据流 → 增强型衡量的齿轮 → 网页浏览 → 显示高级设置 → 关闭 "根据浏览器历史记录事件进行网页更改"（英文为 "Page changes based on browser history events"）。无需关闭整个增强型衡量；章节切换由本站脚本负责上报。

**查看报表**：在 "报告 → 互动 → 网页和屏幕" 中选择 "网页路径和屏幕类"，按 `/fde-course/`（FDE-101）或 `/fde-102/`（FDE-102）筛选；流量来源在 "流量获取" 报告查看。菜单位置可能随 GA4 报告集合而不同。

**发布与验收**：两个仓库分别推送 `main` 后，由各自 GitHub Actions 发布。上线后在 GA4 "实时" 报告查看访问；普通报表通常需要 24–48 小时。浏览首页、切换章节、前进/后退应各记录一次页面浏览，同页目录锚点不新增浏览。用浏览器网络面板检查 Google Analytics `collect` 请求，确认 `tid=G-DSM77VN7ZQ`、`en=page_view` 和对应页面地址。代码测试不会向 GA4 发送模拟流量。

统计从部署生效后开始，无法回补历史。GA4 会使用 Cookie 并向 Google 发送浏览数据；上线前应确认适用的隐私告知与同意要求，不要在网址中放个人敏感信息。大陆网络、拒绝同意或广告拦截可能造成漏记。
