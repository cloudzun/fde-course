# AI 时代的 FDE：认知、流程、团队与中国落地

> **副题：从非标交付到平台飞轮——"卖人力"到"卖能力"的完整方法论**

一套系统讲解 **FDE（Forward Deployed Engineer，前沿部署工程师）** 的方法论与落地手册：它是什么、为什么有效、如何交付（四阶段 SOP）、如何组建团队、中国技术服务商如何对标转型，以及 AI/Agent 时代如何谈成与做成 FDE 项目。

---

## 内容概览（六篇 16 章 + 附录）

| 篇 | 章节 | 内容 |
| :--- | :--- | :--- |
| 第一篇 · 认知篇 | 第1–2章 | FDE 是什么（定义/三重角色/真伪鉴别）、为什么需要（经济学/飞轮/财务证据） |
| 第二篇 · 标杆篇 | 第3–4章 | Palantir 平台与 FDE 体系解剖、经典案例集（含脱敏教学案例） |
| 第三篇 · 流程篇 | 第5–9章 | 四阶段 SOP（Discovery→Prototype→Build→Scale）+ Gate 运行规则 + 能力回注方法论 |
| 第四篇 · 团队篇 | 第10–12章 | 五角色体系、阶段协作、人才培养、HR 专属视角与进阶路径 |
| 第五篇 · 中国实践篇 | 第13–14章 | 中国云厂商实践图谱（含可引用案例锚点）、中国区转型挑战与合规清单 |
| 第六篇 · AI 解决方案篇 | 第15–16章 | AI 解决方案怎么落地：**FDE 让 AI 真正落地**（Echo 谈成 × Delta 做成：合同/ROI、技术栈、场景地图、SOP 9、反模式清单） |
| 附录 | A–I | 官方来源、技术栈清单、术语表、研讨题、甲乙方术语对照、合规速查 |

**贯穿全书的设计**：主线"卖人力→卖能力"、能力回注飞轮、四阶段 SOP+Gate、PPT（人员流程技术）三维框架、三角色↔五角色体系、每篇收尾的「甲乙方对照」专栏、溯源纪律、中国语境（信创/数据不出域/备案）。

## 如何阅读

- **决策层/甲方**：重点读认知篇、标杆篇、中国实践篇导读与小结，以及每篇收尾的「甲乙方对照」专栏，把握战略与 ROI。
- **中层管理者**：深读流程篇、团队篇，掌握交付方法论与组织建设。
- **一线工程师**：细读流程篇四阶段 SOP 与各类模板，并关注 AI 篇（第15–16章）的落地打法。
- **按行业检索**：金融/制造/政务读者可先读 14.5.2「三行业关切对照表」与附录 I「合规速查表」定位重点章节。
